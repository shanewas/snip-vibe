# ✂️ SnipVibe `sv`

**Dead-simple local snippet vault.** Add, fuzzy search, copy, format for Twitter/LinkedIn.

No database. No cloud. Just joy.

## Install

```bash
pipx install git+https://github.com/shanewas/snip-vibe.git
```

## Usage

```bash
sv add "react hook" --tags react,hook
sv search auth
sv copy 3
sv vibe tweet 12   # formats for social
```

Tired of digging through old projects or Notion hell for that one snippet?
